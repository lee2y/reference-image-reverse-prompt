# 参考图反推 Skill

一个将参考图转化为可直接用于生图的中文提示词的 Codex Skill。它根据图片类型和你的参考目的，优先提取最影响还原的细节，例如机位、构图、主体比例、焦点、材质、光影或版式。

## 能做什么

- **整图反推**：从参考图中提取关键视觉关系，输出一份完整、可复制的提示词。
- **局部参考**：只提取指定部位的特征，例如包装表面的纹理或瓶身的一道反光，并应用到目标位置。
- **多图分工**：让不同参考图分别决定构图、产品、材质或环境，再协调它们的比例、透视和光线。
- **成图迭代**：对照参考图和生成结果，修订焦点、构图或材质等偏差。需要长期复用时，可以把具体经验提炼为 Skill 规则。

## 安装

1. 下载并解压 [Skill 安装包](./reference-image-reverse-prompt.zip)。
2. 将整个 `reference-image-reverse-prompt` 文件夹复制到 `~/.codex/skills/`。如果设置了 `CODEX_HOME`，使用 `$CODEX_HOME/skills/`。保留文件夹中的 `SKILL.md` 与 `references/`。
3. 在 Codex 中上传参考图，输入 `$reference-image-reverse-prompt` 和你的要求。

## 调用示例

```text
$reference-image-reverse-prompt
图一参考平视机位和人物比例，图二只参考菜品质感，图三参考环境。
焦点放在盘中的薯片与镊尖上的牛肉，人物在后方并落在焦外。
给我一份完整的中文生图提示词。
```
